# QueueLess – Digital Queue Management System

QueueLess is a web-based digital queue and token management system developed using Java, JSP, Servlets, and MySQL.

## Features
- Student registration and login
- Digital token generation
- Department-wise queue management
- Live token status tracking with automatic refresh
- Staff dashboard for calling, completing, and skipping tokens
- Token cancellation while waiting
- Token history tracking
- Database-backed token management

## Technologies Used
- Java
- JSP and Servlets
- HTML and CSS
- MySQL
- JDBC
- NetBeans IDE
- GlassFish Server

## Purpose
QueueLess aims to reduce physical waiting lines and make queue management more organized and efficient within an institution.

## Project Status
Developed as an academic Advanced Java project.
